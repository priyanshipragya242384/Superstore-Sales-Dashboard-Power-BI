# Sales Analysis Dashboard - Power BI

## Overview

This project is an interactive Power BI dashboard built using the Superstore Sales dataset.

The dashboard provides insights into sales performance, profit, quantity sold, discounts offered, and regional distribution. It allows users to analyze business performance across different regions, customer segments, categories, and sub-categories.

## Objectives

- Monitor overall sales performance
- Analyze profit generation
- Compare sales across regions
- Identify high-performing product categories
- Explore customer segment trends
- Visualize geographical sales distribution

## Dashboard Features

### KPIs
- Total Sales
- Total Profit
- Total Quantity Sold
- Total Orders
- Total Discount

### Interactive Filters
- Region
- Category
- Segment

### Visualizations
- Sales Trend Analysis
- Sales by Region
- Sales by Sub-Category
- Sales Distribution by State
- Regional Sales Comparison

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Data Visualization Techniques

## Dataset

The project uses the Sample Superstore dataset, a widely used dataset for business intelligence and analytics practice.

## Key Insights

- West region generated the highest sales contribution.
- Technology emerged as one of the strongest performing categories.
- Sales were concentrated within a few major sub-categories.
- Regional sales performance showed noticeable variation across the United States.
